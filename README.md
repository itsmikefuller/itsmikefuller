I'm a Pricing Developer at [Munich Re Specialty - Global Markets](https://www.munichre.com/specialty/global-markets-uk/en/about-us.html) (MRS-GM). I work with developers, actuaries, and analysts in the MRS-GM Pricing team to build and integrate specialty insurance pricing models in Python and [hx Renew](https://www.hyperexponential.com/hx-renew/). 

Currently I have built and overseen the development of two [Specie](https://www.munichre.com/specialty/global-markets-syndicate/en/products/specie.html) models and am currently working on data migration for the Cyber model. I have also developed a framework for migrating policies from the Pricing team database to hx Renew via the hx Renew API. I regularly provide Python / hx Renew expertise, technical guidance, and code reviews to members of the Pricing team.

The package contains various statistics and data analysis tools, built from the bottom-up, with a case study on [calibrating a Total Return Index model](https://github.com/itsmikefuller/sdatools/blob/main/case_studies/total_return_index.ipynb).
